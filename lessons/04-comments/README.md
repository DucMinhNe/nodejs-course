# Lesson 04: Comments

Notes for humans, ignored by the engine.

## What you'll learn

- single-line: `// like this`
- multi-line: `/* like this */`
- JSDoc: `/** ... */` documents functions and is read by tooling
- don't over-comment obvious code — explain WHY, not WHAT

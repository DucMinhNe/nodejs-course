# Lesson 14: Arithmetic operators

+, -, *, /, %, ** and increment/decrement.

## What you'll learn

- `%` is remainder (modulo)
- `**` is exponentiation (`2 ** 10`)
- `++` / `--` increment/decrement (prefer `+= 1` for clarity)
- `+` is also string concat — watch types

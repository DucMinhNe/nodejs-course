# Lesson 15: Comparison operators

==, ===, !=, !==, <, >, <=, >=.

## What you'll learn

- `===` strict equality (no coercion) — prefer this
- `==` loose equality (coerces types) — avoid
- `<`, `>` work on numbers AND strings (lexicographic)
- comparing objects compares references, not contents

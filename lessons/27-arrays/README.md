# Lesson 27: Arrays

Ordered, zero-indexed lists.

## What you'll learn

- create with `[]` or `Array.of(...)`
- access by index `arr[0]`; `.length` gives size
- add/remove at end: `push` / `pop`; at start: `unshift` / `shift`
- arrays are objects — `Array.isArray(x)` to test

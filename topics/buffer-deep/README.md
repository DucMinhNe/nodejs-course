# Buffer

Node's binary data buffer (fixed-length, like Uint8Array).

## Key points

- `Buffer.from(...)`, `Buffer.alloc(n)`, `Buffer.allocUnsafe(n)`
- convert with `.toString('utf8' | 'hex' | 'base64')`

## Examples

See `examples/` for runnable demos.

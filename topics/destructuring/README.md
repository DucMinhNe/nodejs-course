# Destructuring

Pull values out of arrays and objects with concise syntax.

## Key points

- array: `[a, b] = [1, 2]`
- object: `{ name, age } = user`
- rename: `{ name: n }`
- defaults: `{ name = 'anon' } = {}`
- rest: `[head, ...tail] = list`

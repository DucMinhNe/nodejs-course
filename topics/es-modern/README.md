# Modern JS features

Recent ECMAScript additions worth knowing.

## Key points

- optional chaining `?.` and nullish coalescing `??`
- logical assignment `||=`, `??=`, `&&=`
- numeric separator `1_000_000`
- top-level await in ESM
- Array.prototype.at(-1) for negative indices
- Object.hasOwn(obj, 'x')
- structuredClone(obj) for deep copy

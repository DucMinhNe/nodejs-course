# Jest fundamentals

Jest for unit + integration tests.

## Key points

- `describe` / `test` / `expect`
- matchers: `.toBe`, `.toEqual`, `.toMatchObject`
- `jest.mock` to replace a module
- snapshot tests for stable structured output

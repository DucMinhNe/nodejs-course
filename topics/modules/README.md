# Modules: CommonJS vs ESM

Node supports both module systems. Mixing them needs care.

## Key points

- CommonJS: synchronous, `require` / `module.exports`
- ESM: asynchronous, `import` / `export`, requires `"type": "module"` or `.mjs`

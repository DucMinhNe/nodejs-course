# Prototypes & Classes

Objects in JavaScript inherit from a prototype chain. Classes are syntactic sugar.

## Key points

- every object has an internal [[Prototype]] (`__proto__`)
- constructor functions + `prototype`
- ES6 `class` syntax
- `extends` and `super`
